# 暖橙品牌主题实施计划

**Goal:** 页面与交互状态统一适配当前暖橙 Logo。

**Architecture:** 更新两页共享令牌，补齐组件交互色和固定主题缩略图；沿用既有主题切换与布局。

**Tech Stack:** CSS、TypeScript、Vitest、Vite。

**Spec:** [暖橙品牌主题与交互色](../specs/2026-11-14-warm-theme.md)。

## 约束与检查重点

遵循 spec 的浅深主题色值，Logo 色值保持原样；文字对比度 ≥4.5:1、焦点色 ≥3:1；危险色优先于品牌 hover；固定缩略图不随主题反转；不改变业务、布局和偏好设置。

## 步骤

- [x] 更新 `src/styles/tokens.css` 两套令牌与选择文本颜色。
- [x] 同步管理页、设置页、页脚 hover / active 颜色与固定主题缩略图。
- [x] 调整纸屑色板，更新 `design/brand-spec.md` 的当前主题说明与旧 spec 的历史说明。
- [x] 计算关键文字组合与焦点对比度，静态渲染代表组件与窄屏，修复验证发现的问题。
- [x] 运行 `make check`、`pnpm build` 和最终 diff 检查。

## 验证结果

- `make check`：格式、lint、类型检查通过，38 个测试文件、276 项测试全部通过。
- `pnpm build`：通过。
- 从实际 CSS 令牌计算 44 组文字配色，浅色最低 4.67:1、深色最低 5.63:1（包含计数徽标）；焦点在检查背景上的最低对比度分别为 3.54:1、5.62:1。
- 使用实际 CSS 渲染浅深主题代表组件，在 728px / 390px 检查静态样式，无水平溢出。
- 以临时状态类映射实际 CSS 伪类，检查 16 个计算样式：主按钮 hover / active、危险按钮前景和背景、搜索 focus-within 与开关 hover 均符合令牌。
- CSS 令牌引用无缺失；Logo 原色不变。已核对最终 diff。
- 未在真实 Chrome 扩展中验收；静态组件预览不替代完整页面与真实浏览器 API 验证。
