# tabstage 实现计划（父计划）

> **For agentic workers:** REQUIRED SUB-SKILL: Use `subagent-driven-development` (recommended) or `executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现 tabstage Chrome MV3 扩展全部 V1 功能（集中式 TAB 管理页）。

**Architecture:** 管理页直连 Chrome API（无 background 状态代理）；`src/lib/` 纯函数层承载全部业务规则（TDD 主战场），React 组件层只做粘合。background service worker 仅负责单例逻辑。

**Tech Stack:** Vite + React 18 + TypeScript strict + dnd-kit + Vitest/Testing Library + 手写 `chrome.*` mock。

**实现规格:** [docs/specs/2026-08-15-tabstage-design.md](../specs/2026-08-15-tabstage-design.md)（已评审）。领域术语见根目录 `CONTEXT.md`，延后项见 `ROADMAP.md`。

## Global Constraints

- Chrome MV3；permissions 仅 `["tabs", "storage"]`，任何任务不得新增权限
- 包管理 pnpm；构建 Vite（禁用 crxjs 等扩展框架）；拖拽仅 dnd-kit；i18n 不引第三方库
- 语言标签全链路 `zh-CN`（禁用 `zh-Hans`）；字典文件名 `zh_CN.json`；`_locales/zh_CN/`
- URL 归一化全项目唯一实现：`src/lib/url.ts#normalizeUrl`（去 hash）
- 管理页路径常量唯一来源：`src/lib/manager-url.ts#MANAGER_PATH = 'src/manager/index.html'`
- 音效纯 Web Audio API 合成，无音频文件
- 代码注释用简体中文；TDD（先写失败测试再实现）；每个任务独立提交
