# 重复数徽标去重入口

## 目标与方案

按已确认的交互方案复用重复数徽标，不新增独立行操作按钮。默认显示 `×N`；悬停记录行或键盘聚焦徽标时展开为「去重 ×N」，呈现按钮样式，提示「去除此组重复标签」。全部模式与窗口模式一致，文案支持中英文。英文操作文案为 `Dedupe`，悬停提示为 `Dedupe this group`，与全局去重入口保持一致。

## 行为

- 点击徽标只对所在重复组执行去重，范围跨窗口且不受搜索过滤影响。
- 复用 URL 归一化与现有去重计划：保留全部固定标签；没有固定标签时保留最近访问的标签。全固定标签组不展示重复徽标。
- 点击或键盘激活不触发行跳转或拖拽；聚焦徽标时展示同组保留／待关闭预览，失焦后清除。
- 复用现有关闭动效及完成提示；全局一键去重继续沿用现有行为。

## 验收

组件测试验证点击、键盘操作与预览事件；管理页测试验证两个模式下跨窗口、搜索隐藏成员、固定标签优先及其他重复组不受影响。运行项目检查和生产构建。
