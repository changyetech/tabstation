# 已保存窗口命名

按用户确认，将单个窗口标签集合的产品名称从 Saved sessions / 已保存会话统一为 Saved windows / 已保存窗口。保存入口使用 Save window / 保存窗口；恢复、删除、空态、搜索、设置、通知和地址栏提示同步采用窗口措辞。恢复仍创建新窗口，保存的集合继续保留并可反复打开。

本次只变更用户可见名称及当前产品文档。内部 `sessions` 存储键、`SavedSession` 类型、模式值、组件名和 i18n 键保持兼容，不迁移数据，不改用户自定义名称。历史设计文档沿用当时术语。

验收：现有测试断言同步新名称，运行 `make check` 和 `pnpm build`。
