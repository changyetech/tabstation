# Tab Station 管理页重设计（完全匹配 refs/design）

- 状态：待评审
- 日期：2026-08-16
- 设计稿（视觉契约，normative）：`refs/design/tab-station-home.html`、`refs/design/tab-station-settings.html`、`refs/design/brand-spec.md`
- 前置 spec：[2026-08-15-tabstation-design.md](2026-08-15-tabstation-design.md)（下称「旧 spec」）。本 spec 只声明**增量与覆盖**；未提及的行为规则（去重判据、稍后阅读语义、会话语义、拖拽、单例、i18n 机制、时间展示、关闭动效、测试策略）沿用旧 spec。

## 1. 目标与裁决记录

以 `refs/design` 两张屏幕稿为**视觉与交互契约**完全重绘管理页，并新增设计稿承载的功能。盘问阶段与用户达成的裁决：

| # | 议题 | 裁决 |
|---|---|---|
| 1 | 匹配强度 | 视觉与交互完全服从设计稿；设计稿新增功能真实现；设计稿没画的现有功能逐条裁决 |
| 2 | 旧 UI | 完全替换，旧样式与 `SettingsDialog` 删除，不留切换开关 |
| 3 | 响应式 | 桌面优先（≥1024 一等公民）；窄窗口不横向溢出、优雅降级即可，不做移动端视口适配 |
| 4 | 设置入口 | 设置页注册为扩展 options 页（浏览器「选项」入口打开）；**管理页内不加设置入口**，工具栏 ⚙ 按钮删除 |
| 5 | 历史按钮 | 删除（旧 spec §5.8 废止） |
| 6 | 「数据」分组 | 不做。设计稿 index.html 导航文案中的「数据与关于」以设置页屏幕稿为准，无导入/导出/清空功能 |
| 7 | 去重保留规则 | 维持旧 spec §5.6（混合组保留全部 pinned；纯普通组保留 `lastAccessed` 最新者）。设计稿原型的「保留组内第一个」是简化写法，不采纳 |
| 8 | 搜索 | 两侧皆无，维持旧 spec 非目标，不引入 |

## 2. 视觉系统（token 先行）

实现前先在 `src/manager/styles.css`（或独立 `tokens.css`，两页共享）冻结 token，全部取自设计稿 `:root` / `html[data-theme="dark"]`，不得改值、不得引入新色：

- **核心六色**（OKLch，light/dark 成对）：`--bg` / `--surface` / `--fg` / `--muted` / `--border` / `--accent`。
- **派生**：`--accent-strong`（文本级对比 ≥4.5:1）、`--accent-hover`、`--on-accent`、`--accent-tint`、`--hover`、`--seg-bg`、`--success(-tint)`、`--danger(-tint)`、`--warn`、`--block-shadow`、`--pop-shadow`、`--frost`（毛玻璃）、`--head-grad`。
- **字体**：Display / Body 均为 SF Pro 系统栈；数字一律 `tabular-nums`（`.num`）；13px 基准正文、CJK 行高 ≥1.7；Latin display 负字距、CJK 不加字距。
- **图标**：全部 1.7px 描边 monoline SVG（`currentColor`），取设计稿 `ICONS` 路径数据；**废除全部 emoji 图标**。favicon 优先用真实 `favIconUrl`，缺失时回退设计稿式字母徽标（域名首字符 + 背景色派生）。
- **品牌规则**：强调色每屏 ≤2 处（一键去重 CTA、「当前」窗口标记）；hover 反馈走 `--hover` 背景位移或边框，前景对比度只升不降；危险操作 hover 配 `--danger` + tint。
- **主题**：三态偏好 浅色/深色/自动（默认自动）。经 `data-theme` 属性切换；自动态监听 `prefers-color-scheme`。管理页与设置页共用同一偏好，偏好存 `chrome.storage.local`（设计原型的 `localStorage` 仅为演示，不采纳），经 `storage.onChanged` 跨页即时同步。

**扩展图标**：以设计稿品牌标记（圆角方框 monoline logo，深底浅标）输出 16/32/48/128 PNG，补进 manifest `icons` 与 `action.default_icon`。

## 3. 页面结构

### 3.1 管理页（Home）

自上而下三层，最大宽 1200px：

1. **Hero**：左侧大字问候（按小时切换：夜深了/上午好/中午好/下午好/晚上好，每分钟刷新）+ 中文长日期（`Intl.DateTimeFormat('zh-CN')`，月/日/星期）；右侧五项全局统计大数字：**窗口、标签页、域名、组重复、待读**（管理页自身按旧 spec 规则隐身于所有计数）。
2. **控制条**（sticky 吸顶，`--frost` + blur）：左端「模式」分段控件（窗口模式/全部模式/已保存会话，2026-08-16 修订：新增第三段，会话从侧栏迁入主区，见 §5.5），右端「一键去重」CTA。**无历史按钮、无设置按钮**。（2026-08-16 修订）视图不可切换、无视图段控：窗口模式固定列表视图，全部模式固定域名视图。
3. **主体网格** `minmax(0,1fr) 300px`：左主区 + 右侧 sticky 侧栏（仅稍后阅读一个面板，2026-08-16 修订：已保存会话迁入主区）。（2026-08-16 修订）稍后阅读为空时 `<aside>` 整个不渲染，网格塌成单栏（`.layout.no-aside`），主区满宽。

响应式（无横向溢出）：≥1160px 全部模式（域名视图）双列瀑布（CSS columns）；≤1000px 塌成单列、侧栏取消 sticky；≤720px 隐藏 tab 行域名列与 favicon 叠层、问候字号缩小。（2026-08-16 修订）主区满宽（no-aside）时改为多列瀑布，列数随主区宽度自适应：窗口模式 / 已保存会话（`.win-flow`）`columns: 480px 2` 最多 2 列，「新建窗口」幽灵按钮随卡片一起排入列流（不独占整行）；全部模式（`.dom-flow`）`columns: 340px 3` 最多 3 列；不足最小列宽自动塌回更少列。

### 3.2 设置页（新 surface）

- 新入口 `src/settings/`（独立 html + tsx），manifest 注册 `options_ui: { page, open_in_tab: true }`。设置页不是管理页，不参与单例判定，也在一切列表/计数中隐身（同属扩展自身页面）。
- 顶栏：品牌标记 + 「Tab Station」 + 版本号（读 manifest version）。
- 左侧 sticky 锚点导航：外观 / 行为 / 语言 / 快捷键 / 关于（≤760px 隐藏导航、单列）。
- 副标题与产品承诺：「所有改动即时保存并生效，无需确认。」每次改动 toast「已保存，即时生效」。
- 旧 `SettingsDialog` 及其入口删除。

## 5. 功能行为（新增与覆盖）

### 5.1 主区展示

- **窗口区块头**：`窗口 N` + 当前窗口「当前」胶囊（强调色、区块整体强调色描边）+ 最多 4 个 favicon 叠层 + 「N 个标签页 · N 固定」 + ghost 按钮「保存会话」「关闭窗口」（danger hover）。
- **标签行**（单行密排 min-height 34px）：拖拽手柄（hover 显形，pinned 无）、favicon、pinned 图标、标题、域名、`×N` 重复徽章（warn 色）、相对时间。整行可点 = 激活跳转到该 tab；`Enter`/`Space` 等效。
- **favicon 来源**（2026-08-16 修订）：统一封装为 `Favicon` 组件，三级回退——① tab/条目声明的 `favIconUrl`；② 无声明或图片加载失败（如跨站热链被拒）时，经 Chrome 本地 favicon 缓存取图（扩展 `_favicon/` API，manifest `favicon` 权限，零网络请求，未加载/被 discard 的 tab 也可命中）；③ 页面 URL 也缺失时回退字母徽标。适用于标签行、窗口头 favicon 叠层、域名头（取组内任一有声明图标的 tab 代表整组）、稍后阅读与会话条目。注意不可只用 `_favicon` 单级方案：favicon 库按「已访问页面 URL」记录，从未实际加载过的页面（后台打开、会话恢复未点开）查不到图。
- **行内操作组**：hover 时在行尾**原位替换时间显示**（无浮层）：收进稍后阅读（pinned 无）、拆到新窗口（pinned 无）、移动到其他窗口（仅窗口数 >1，弹既有 MoveMenu，样式照稿 popover）、关闭（danger）。
- **域名视图**（2026-08-16 修订：仅全部模式，窗口模式固定列表视图）：跨窗口按域名聚合为独立区块（带域名色顶条），标签行显示标题 + URL 两行；favicon 仅出现在域名头（代表整组），标签行内不再逐行显示（同域名下逐行重复无信息量，对应设计稿 `tabRowHtml` 的 `noFav`）。域名头带**域名批量操作组**（hover 浮现）：全部收进稍后阅读、拆到新窗口、关闭全部（前后两者跳过 pinned；若目标全为 pinned 则 toast「该域名只有固定标签，未处理」）。作用域为全浏览器。
- **空状态**：所有窗口清空（管理页除外）→ sparkle 图标 + 「所有窗口都已清空——干得漂亮。」 + 新建窗口按钮。

### 5.2 展示条数折叠

区块内 tab 行数超过 `visibleTabs` 时截断，底部「还有 N 个标签页 · 展开」/「收起」。适用：窗口模式（按窗口）与全部模式（按域名区块）。展开状态是会话内存状态，不落盘。去重预览态下不折叠（见 §5.4）。

### 5.3 新窗口类动作

统一遵循 `newWindowMode`：`max` → `chrome.windows.create` 后进入全屏（`state: 'fullscreen'`，2026-08-16 修订：原为 `maximized`，在 macOS 上只是撑满屏幕的普通窗口而非全屏）；`same` → 尺寸/位置复制当前窗口。适用于：拆到新窗口（单条 / 整域名，实为 `chrome.windows.create` + `chrome.tabs.move`）、稍后阅读「新窗口打开」与「全部打开」、会话恢复与会话条目「新窗口打开」、主区底部「新建窗口」幽灵按钮（新开空窗口）。

### 5.4 去重（覆盖旧 spec 的 UI 规则，判据不变）

- 「一键去重」按钮**仅在存在重复组时渲染**，文案带待关数 `−N`；已保存会话模式下不渲染（预览只作用于活动标签页，2026-08-16 修订）。
- hover 按钮 = 全局预览态：主区只保留重复组成员；保留行绿底 + 左绿条，待关行红底 + 左红条 + 标题删除线（不加额外 ✕ 标记——hover 行时会与行操作区的关闭按钮重复，2026-08-16 修订）；无成员的区块整体隐藏；预览态禁用折叠、拖拽与「新建窗口」按钮。移开即恢复。
- **hover 任一重复标签行**：同组所有行以同款绿/红样式高亮（折叠中的组员不强制展开）。
- 点击执行：批量关闭动效（音效一次、粒子逐行错开）→ toast「已关闭 N 个重复标签页」。

### 5.5 侧栏面板

- **稍后阅读**：清单为空时整卡隐藏，非空才渲染（2026-08-16 修订，覆盖「常驻 + 空态」的旧裁决）。头部「N 条」 + 「全部打开」（仅非空时显示）：在一个新窗口打开全部并清空清单，语义与单条「打开即移除」一致。行 hover 时时间被操作组原位替换：新窗口打开（移除）、删除（danger，退场动效）。
- **已保存会话**（2026-08-16 修订：从侧栏迁入主区，作为控制条第三种模式）：选中「已保存会话」段后主区渲染，每个会话一张与窗口区块同款的卡片（`win-block` 样式）。卡片头：会话名（重命名就地 input，Enter 提交/Esc 取消/blur 提交）+ 最多 4 个 favicon 叠层（按域名去重，同窗口区块头）+ 「N 个标签页 · M/D HH:MM 保存」 + ghost 按钮「恢复」（模板式，会话保留）「重命名」「删除」（danger）。**无折叠箭头**，条目直接平铺列出，超出 `visibleTabs` 走 §5.2 折叠。条目行：标题可点单独打开（当前窗口）、新窗口打开（条目保留）、移除此条（删空则会话消亡）；条目拖拽排序沿用旧 spec。无会话时主区显示空态文案。

### 5.6 动效与反馈（照稿）

- 模式切换：主区 180ms 上浮淡入重放；首屏窗口区块 fadeUp 逐个错开 50ms；hover 操作组 120ms 右滑浮现；会话展开 160ms 下落淡入；所有按钮按压位移 1px。
- 关闭动效沿用旧 spec 交互签名；toast 黑底居中底部 `role="status"`。
- 完整 `prefers-reduced-motion` 支持；`:focus-visible` 统一 2px 强调色描边；可点行 `role="button" tabindex="0"`。
- loading/error 态从简：本地 API 极快，不做骨架屏；空态仅照稿实现。

### 5.7 触屏适配（2026-08-16 新增）

- 判定用 CSS `@media (hover: none)`（主输入设备无悬停能力），纯 CSS 实现，无 JS 分叉；触屏笔记本等混合设备主输入为鼠标时不受影响。
- 该模式下所有 hover 浮现的操作组（标签行 `.row-acts`、稍后阅读行 `.rl-acts`、窗口头/域名头 `.dom-acts`）常驻显示；行尾相对时间（`.tab-time`/`.rl-time`）不再渲染占位（原「hover 原位替换」语义退化为「操作组独占行尾」）。
- 拖拽手柄 `.drag-grip` 常驻半透明显示（不再依赖行 hover 显形）。
- 去重 hover 预览、行高亮等纯增强反馈在触屏下自然缺失，不做替代交互（点击执行路径不受影响）。

## 7. 验收标准

1. `make check` 全绿；新增行为（折叠、拆窗、域名批量、设置项、主题解析、去重按钮显隐）有对应单测。
2. 管理页与设置页在 1440×900 浅色/深色下与设计稿逐区块目视比对一致（结构、间距节奏、色彩、图标、状态）。
3. 窗口拖窄至 ~700px 无横向滚动，三档降级行为符合 §3.1。
4. 设置改动即时生效并跨页同步；主题三态切换正确（含系统切换时 auto 跟随）。
5. 工具栏无历史/设置按钮；扩展「选项」入口可达设置页；扩展图标非默认灰块。
6. 旧 `SettingsDialog`、旧 styles、emoji 图标全部移除，无死代码残留。
