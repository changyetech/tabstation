# 俄语、韩语、日语、法语国际化

## 范围与行为

- 在既有英语、简体中文基础上增加 `ru`、`ko`、`ja`、`fr`，覆盖管理页、设置页、地址栏搜索及 Chrome 扩展描述和快捷键说明。品牌名保持 `Tab Station`。
- 设置语言选择器保留自动、中英文，新增 Русский、한국어、日本語、Français；修改即时持久化，并通过既有 storage 事件同步页面。不迁移存储数据。
- 自动模式按浏览器语言主标签匹配，忽略大小写，支持地区变体（如 ru-RU、ko-KR、ja-JP、fr-CA）；中文变体继续统一简体，未知语言回退英语。
- 沿用本地 JSON 字典，不增加依赖或网络请求。页面与 service worker 共用不依赖 React 的字典模块，避免遗漏语言。
- 保留 `{name}` 插值及 `{n|one|other}` 形式；增加 `{n|one|few|many|other}`，按 `Intl.PluralRules` 选择，满足俄语 1 / 2–4 / 5 等词形及法语零数量规则。按语言缓存规则实例。
- 日期及相对时间继续使用既有 Intl 机制；Chrome 原生 manifest 文案跟随浏览器语言，独立于扩展内设置。

## 验收

- 自动地区语言解析、手动覆盖、未知语言回退均有测试。
- 六套字典键与插值参数一致，四套新增 manifest 文案齐全。
- 设置页分别选择四种新语言后持久化并立即显示对应文案，地址栏搜索遵循同一语言设置。
- 俄语数量 0、1、2、5、11、21、22、25 及法语 0、1、2 的文案正确，原有英文行为保留。
- `make check` 与 `pnpm build` 通过。
