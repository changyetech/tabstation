# 工具栏搜索：管理页主区即时过滤

## 1. 目标

在管理页控制条的三段模式按钮右侧、「一键去重」按钮左侧加入搜索框。用户输入时，当前主区即时过滤；清空搜索词后恢复原展示。

## 2. 决策修订

[2026-08-15-tabstation-design.md](2026-08-15-tabstation-design.md) §2 曾否决管理页内的 tab 过滤搜索框。本 spec 将该否决收窄为：不做历史搜索、不做网页搜索；当前标签列表的即时过滤重新纳入产品。理由是用户已明确需要在集中管理页中按关键词快速定位已有标签，且搜索范围仍限于 Tab Station 自有数据，不引入第二用途。

## 3. 行为

- 搜索框位于三段按钮与「一键去重」按钮之间，始终可见，并占满控制条中两者以外的剩余空间。
- 搜索词是页面内存状态，不写入 `chrome.storage.local`，切换模式后保留。
- 全部模式与窗口模式：按标签标题和 URL 做不区分大小写的子串匹配；空窗口和空域名分组隐藏。
- 已保存会话：按会话名或任一条目的标题 / URL 匹配；命中的会话整卡保留，避免过滤隐藏行导致会话内拖拽索引错位。
- 无匹配时主区显示「没有匹配的标签页 / 会话」空态，不提供网页搜索。
- 搜索只影响主区展示。Hero 统计、重复组统计与一键去重仍按全浏览器可见标签计算。

## 4. 验收

1. 在任意非会话模式输入关键词，仅保留标题或 URL 命中的标签，空分组 / 空窗口消失。
2. 在会话模式输入关键词，仅保留命中会话；清空后恢复。
3. 一键去重的待关数量不因搜索词缩小。
4. 新增交互有组件测试与 App 集成测试覆盖。
