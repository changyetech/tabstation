# 暖橙品牌主题与交互色

- 状态：已实现；项目检查、生产构建与静态组件渲染验证通过。

## 目标与方向

按用户要求，将管理页、设置页的页面主题与按钮交互色适配已选定的 A「标签成 T」Logo。
采用暖纸白 / 陶橙浅色主题、可可棕 / 浅橙深色主题。相比仅把蓝色换为 Logo 橙，此方案同时协调中性色和状态层次；不采用大面积高饱和橙底，避免干扰密集标签阅读。

## 范围与约束

- 共享主题令牌、管理页交互状态、设置页控件和主题缩略图、页脚链接、纸屑配色及品牌规格。
- 保留 Logo 的 `#ED693C` / `#FFF7E8`；正文、小字号按钮和选中态使用对比更强的同色系色阶。
- 保留浅色 / 深色 / 自动三种偏好、即时保存、现有布局与全部业务行为。不新增依赖或配置，不重画 Logo，不提交或发布。
- 域名 favicon 与按域名生成的装饰色保留其识别用途，不强制改成橙色。

## 交互规则

- 主按钮区分默认、hover、active；模式选中、当前窗口、设置导航、主题卡、单选与开关沿用同一橙色语义。
- 次按钮和普通图标的 hover 使用橙色文字与浅橙底；危险操作继续优先使用玫瑰红与专属淡底。
- 搜索、重命名输入、键盘焦点和拖拽落点使用橙色强调；列表 hover 保持低饱和暖中性底。
- 警告、危险、成功分别使用琥珀、玫瑰红、绿，并保留文案和图标语义。

## 验收

- 浅深主题中，正文、辅助文字、主按钮各状态、选中标签、状态提示等关键文字组合对比度不低于 4.5:1；焦点色与页面 / 卡片对比度不低于 3:1。
- 静态渲染检查两页代表组件的浅深主题和窄屏，覆盖按钮 hover、active、focus、选中、危险操作与设置开关。
- 运行 `make check` 与 `pnpm build`，检查 CSS 令牌引用和主题覆盖；不为纯视觉值编写镜像测试。
- 如未在真实 Chrome 扩展中验收，交付时明确说明。
