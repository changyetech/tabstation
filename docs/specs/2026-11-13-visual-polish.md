# 管理页与设置页视觉打磨

## 目标与范围

按用户认可的美化建议，提升文字可读性、深浅主题层次和操作稳定感。沿用 React、现有主题令牌及浏览器本地能力，不引入依赖，不改变标签管理、稍后阅读、会话和存储规则。

## 设计选择

采用现有极简界面的渐进打磨：较大正文、安静的辅助色、稳定操作区及克制动效。未采用整页重构或装饰性主题扩展，避免降低内容密度和增加偏好设置负担。本文为本轮视觉数值依据，替代相关 CSS 中“逐字照搬旧设计稿”的注释约束。

- 管理页容器最大宽度 1360px；问候语 28px，窄屏 26px；统计数字 20px。
- 标签标题 14px，辅助文字主要为 12px；卡片圆角 12px、控件圆角 8px；间距以 4 / 8 / 12 / 16 / 24px 为主。
- 浅色采用微灰页面与白色卡片；深色区分页面、卡片、悬停层次。蓝色用于选中、焦点和主要操作，保留既有成功、危险、警告色语义。域名装饰线降低透明度。
- 保留窗口双列、全部模式域名卡片；小屏工具栏搜索独占一行，设置控件可换行，不能产生水平溢出。
- 标签、会话和稍后阅读操作区始终保留空间。时间与按钮共用固定区域，通过透明度切换；键盘聚焦等效于悬停，触屏按钮常驻。域名批量操作同样预留空间。
- 悬停反馈 140ms、模式切换 200ms、首屏 240ms，关闭 CSS 退场 200ms、位移缩至 8px；保留既有关闭编排时长、音效、纸屑与失败回滚。系统减弱动态效果继续生效。
- 设置页共享字体、主题层次、控件尺寸、焦点与选中态；成功提示在对应分组标题旁显示 2.2 秒，连续修改重置提示时间，切换分组时仅显示最新分组，语言切换后提示使用当前语言。保留即时保存语义。

## 验收

运行设置页反馈回归测试、完整 `make check` 与 `pnpm build`；检查 CSS 在窄屏、长标题、键盘聚焦、触屏与减弱动态效果下的规则。没有真实浏览器验收时明确说明限制，不以 jsdom 测试代替视觉验收。

## 窗口模式显示完整 URL 信息

用户已确认采用标题与 URL 两行排版。窗口模式复用 `TabRow` 的 `subUrl` 样式，保留行内 favicon、固定标记、拖拽、重复提示及固定占位的时间/操作区。第一行显示标题，第二行显示 URL，仅省略 HTTP(S) 协议前缀，保留路径、查询参数和锚点；非 HTTP(S) 地址保留协议。URL 超长时沿用单行省略，悬停 URL 显示包含协议的完整地址。URL 缺失时只显示标题，不生成空 URL 提示。

全部模式的既有两行布局与已保存会话的单行布局保持；共用 URL 子标题补充完整地址悬浮提示。无需新增配置、依赖或修改存储模型。

验收覆盖 HTTP/HTTPS、查询参数与锚点、chrome/file 地址、缺失 URL，以及窗口模式下 URL 点击仍能激活标签。运行相关组件测试、`make check` 和生产构建。
