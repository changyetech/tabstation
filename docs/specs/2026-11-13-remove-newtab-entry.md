# 移除新标签页入口

- 日期：2026-11-13
- 状态：按用户要求实施
- 替代：[新标签页接管设计](2026-08-17-newtab-override.md)。该设计保留为历史快照，不再描述当前行为。

## 行为与范围

扩展不再接管 Chrome 新标签页。管理页保留扩展图标与 `open-manager` 快捷键入口，管理页单例规则保持不变。既有地址栏搜索功能保持不变。

移除 manifest 的新标签页覆盖配置、Vite 新标签页构建入口、`NEWTAB_PATH`、`src/newtab/` 及专属挂载测试。默认视图仅用于管理页，同步中英文文案、领域词汇与当前架构文档。

自有页面仍按扩展 URL 前缀识别，管理页与设置页继续从列表、重复统计和会话快照中排除，关闭窗口时继续受到保护。将原先使用已移除入口的通用保护测试改为设置页用例。

## 验收

- `make check` 通过，管理页单例及自有页面保护测试保持通过。
- `pnpm build` 通过，构建 manifest 不含 `chrome_url_overrides`，不生成新标签页 HTML 或脚本。
- 构建 manifest 保留 `action` 与 `commands.open-manager`，管理页及设置页产物存在。
